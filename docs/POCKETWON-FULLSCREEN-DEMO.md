# 포켓WON 화면 고정·가상 데이터 표시

2026-10-04 사용자 요청에 따라 기존 ‘작은 화면에서 세로 스크롤 허용’ 기준을 한 뷰포트 안에 맞추는 기준으로 변경했다.

## 화면 구조

- 루트 프레임은 `100dvh`와 safe area를 사용한다. 문서와 작업 영역에 스크롤바를 만들지 않는다.
- 홈에는 상단바가 없으며, 첫 파란 카드 위에 작은 여백을 유지한다. 세로 화면은 4행, 폭 700px 이상은 2열×2행으로 카드가 가용 영역을 채운다.
- 하단바는 모든 탭·세부 화면에서 84 CSS px, 중앙 포켓WON 버튼은 60×60px, 나머지 아이콘은 28px이다. 본문 크기 조정과 분리했다.
- 긴 세부 화면과 대화상자 본문은 실제 콘텐츠 크기를 측정해 가용 영역 안으로 맞춘다. 입력창의 헤더·확인/취소 버튼은 본문과 분리한다. 가족 약속 입력은 2열로 압축했다.
- 가상 키보드가 열리면 입력창은 키보드를 제외한 VisualViewport를 사용한다. 뒤에 있는 앱 하단바의 크기·구조는 변경하지 않는다.
- 작은 화면·200% 글자 확대에서는 전체 내용이 들어가도록 본문이 축소될 수 있다. ‘본문 모두 표시’와 ‘모든 본문 요소의 확대 후 물리 크기 유지’를 동시에 보장하지는 않는다. 하단바는 축소하지 않는다.

## 브라우저 전체 화면

일반 웹페이지는 진입만으로 브라우저 주소창을 제거할 수 없다. `전체 → 전체 화면` 버튼은 사용자 클릭으로 Fullscreen API를 실행하고, 지원하지 않는 브라우저에서는 홈 화면 추가 안내를 표시한다. manifest는 fullscreen/standalone 실행 모드와 앱 아이콘을 제공한다. iOS 등에서는 운영체제가 선택한 standalone 모드로 실행될 수 있다. 네이티브 설치·실제 모바일 키보드는 기기에서 확인하지 않았다. 오프라인 동작은 추가하지 않았다.

## 가상 데이터와 저장

기본 접속은 `PWDemo`의 읽기 전용 예시 데이터다. 잔액 32,000원, 용돈 85,000원, 지출 53,000원, 목표 45,000/100,000원과 7일 거래를 보여준다. 날짜는 최근 완료된 일요일까지의 예시 주간이며 실제 오늘의 금융 실적을 뜻하지 않는다. 도넛은 예시 주간 중 표시 월에 해당하는 거래를 집계하므로 월 경계에서는 전체 주간 지출과 다를 수 있다.

홈의 ‘가상 데이터’, 다른 화면의 ‘데모’, 기능 화면의 ‘가상 데이터’ 표기로 예시임을 알린다. 챌린지와 AI/제품 서비스 화면도 예시 값이며 실제 분석·계좌·서버 연결은 없다.

`전체 → 실제 기록 보기` 또는 `?demo=0`으로 기존 로컬 기록에 돌아간다. `?demo=1`은 가상 화면이다. 개발자 Preview는 기존 방식으로 분리된다. 가상 모드에서는 금융 저장 버튼과 최종 저장 경로를 차단한다. 가상 모드 자체는 기존 저장소를 읽거나 쓰지 않으며, 실제 모드에서는 기존 저장 계약을 그대로 사용한다. 기타 제품 초안은 기존처럼 메모리에만 존재한다.

- 보존: `state.js` 금융 계산·저장 키·스키마, 캐릭터 이미지·시트·매니페스트·재생 타이밍·모션 예산
