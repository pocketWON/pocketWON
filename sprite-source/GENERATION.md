# PocketWON sequential frame production

Use the built-in image_gen tool, transparent_background=true. Generate exactly one frame per request. Never generate a contact sheet or draw frames with code.

Immutable single-character master: `sprite-source/master/pocketwon-canonical.png` (512 square, grounded foot center 256,420). The original design reference crop is `sprite-source/master/pocketwon-motion-reference.png`. Inspect every local reference with view_image before use. First reference is the canonical identity master; second reference is the preceding frame. For a neutral profile, edit the canonical master changing only its prop. All body/face/clasp geometry must remain unchanged.

Common prompt: Generate exactly ONE PocketWON sequential sprite frame, never a grid. Input 1 is the immutable identity/camera/scale reference; input 2 is the previous sequential frame to edit. Keep artwork except the specifically requested pose/expression. Exact same opaque white bean/wallet body, asymmetrical folded top, big dark oval eyes, eye spacing, dark navy-blue outline thickness, clasp accessory ALWAYS on viewer RIGHT, tiny hands and feet. Same front camera, same scale and exact canvas coordinates. Square canvas. Grounded feet center at (50%,82%). Head y approximately27%, body width about46% of canvas. Single flat 2D editorial line-art character. No UI, text, letters, numbers, graphs, background, shadow, border or panels. True transparent alpha, wide transparent margins. Do not zoom, crop, recenter, or change proportions. Props pale blue, coins muted gold. Preserve identity over posing.

Each profile needs unique generated files neutral, glance, half, blink, prepare, anticipate, peak, follow, settle, return. Idle ordered frames: neutral,glance,half,blink,glance,neutral. Action ordered frames: neutral,prepare,anticipate,peak,follow,settle,return,neutral. Duplicate neutral/eye frames are intentional animation holds and reversal. Every unique pose must be AI generated individually.

Generate neutral first, then sequential idle eye edits. Use neutral as the initial reference for the separate action chain; then reference the previous action frame. Keep all props unaltered during idle. glance changes gaze slightly to viewer right; half lowers eyelids halfway; blink closes both eyes naturally. No whole-body scaling for idle. Action includes anticipation and prop follow-through.

Save each actual prompt to sprite-source/prompts/PROFILE/FRAME.txt before calling image_gen. Tool output_hint contains the saved generated PNG path. Preserve/import with scripts/import-sprite-frame.py PROFILE FRAME GENERATED_FILE PROMPT_FILE --references REF1 REF2. This resizes the ENTIRE square canvas to512; never crop/recenter per pose. Master prepared once before sequencing. Inspect the imported source with view_image. Regenerate drift/artifact frames rather than papering over with CSS or per-frame transforms.

Production packer creates 384px cells, transparent horizontal lossless WebP/PNG strips and 384px posters. Source and provenance do not deploy. Profile names balance,record,report,goal,all; success has action only. Success uses nine unique poses: neutral,crouch,raise,lift,apex,drift,land,recover,settle, then reuses neutral for the tenth slot.

Final accepted set: 59 individually generated poses, 80 packed cells, 11 sheets. Grounded foot baselines stay approximately y420–422; goal peak/follow and success lift/apex/drift intentionally leave the ground. Rejected drift, duplicate-outline and ground-anchor variants remain in `rejected/` and are never packed. Each profile's prompt folder contains QA notes or review metadata.
